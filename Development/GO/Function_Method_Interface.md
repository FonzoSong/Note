在GO里，函数、方法、接口是三个不同层面的概念：
- 函数：一段可执行的代码，是具体实现；
- 方法：带接收者的函数，属于某个类型；
- 接口：一族方法签名的集合，是抽象的行为契约；

> [! TIP]
>函数是“做什么“的具体代码；方法是”某个类型能做什么“的函数；接口是”任何类型只要能做到这些，就能被当做这个接口用“

| 维度  |        函数         |             接口             |
| :-: | :---------------: | :------------------------: |
| 本质  |      具体可执行代码      |        抽象类型 / 行为契约         |
| 声明  | `func F(...) ...` | `type I interface { ... }` |
| 内容  |    参数、返回值、函数体     |           方法签名集合           |
| 实现  |      直接写函数体       |         由其他类型隐式实现          |
| 调用  |       直接调用        |        通过接口变量动态调用方法        |
| 零值  |       `nil`       |           `nil`            |
| 比较  |   只能和 `nil` 比较    |   可比较，但动态值不可比较时可能 panic    |
| 用途  |       执行逻辑        |         解耦、抽象行为、多态         |

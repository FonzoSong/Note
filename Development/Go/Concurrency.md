# Goroutines

由Go 运行时管理的轻量级线程；
在函数名前添加`go`会启动一个新的goroutine来运行该程序；
且Goroutines 运行在同一个地址空间内，因此对共享内存的访问必须同步；

# Channels

通道，一种带类型的通路，可以通过它使用通道操作符 `<-`发送和接收值。
在使用前必须创建

```go
ch := make(chan int)
```

默认情况下，发送和接收操作会一直阻塞，知道另一端准备就绪。
`goroutines` 无需显示使用锁或条件变量即可完成同步。

## Buffered Channels

缓冲通道，将缓冲区长度作为`make`的第二个参数，即初始化一个带缓冲的通道；

```go
ch := make(chan int, 100)
```

向通道发送数据时，只有缓冲区已满才会阻塞；接收操作会在缓冲区为空时阻塞；
> [!TIP]
> 可以理解为一个固定容量的“队列”，底层实现类似环形队列；

## `range`和`close`

在range 获取通道时第二个值用作检测通道是否已关闭；

```go
c := <-ch
for i := range c
// 不断接收值直达通道关闭
```

**只有发送者应该关闭通道，接收者不应关闭。向已经关闭的通道发送值会引发`panic`**
PS：通道与文件不同，通常不需要关闭。只有在必须告知接收者不会有新值才需要关闭通道，e.g：终止`range`循环;
